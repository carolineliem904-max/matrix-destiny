# Product Plan

## Milestone 1: Verified Architecture, Unverified Methodology

Build a working bilingual MVP shell without inventing Destiny Matrix formulas.

Included:
- Landing page and date-of-birth form
- Optional name or nickname
- Indonesian and English language selection
- Deterministic calculation API
- Responsive SVG matrix chart
- Raw calculation details
- Interpretation lookup with small draft records
- Positive and shadow expressions
- Non-LLM summary assembly
- Validation and error states
- Mobile-friendly UI and accessibility basics
- Calculation and API tests
- Reflection/entertainment disclaimer

Excluded:
- Authentication
- Payments
- Compatibility readings
- PDF generation
- Annual forecasts
- Vector database
- AI-generated interpretation
- Analytics or research-data collection

## Milestone 2: Methodology Integration

Replace `UnverifiedPlaceholderMethodology` only after the definitive formulas are supplied and documented in `docs/METHODOLOGY.md`.

Acceptance criteria:
- Every position has a documented formula.
- Every formula has fixture coverage.
- Methodology version changes are explicit.
- Historical readings can identify which methodology version produced them.

## Milestone 3: Interpretation Expansion

Expand bilingual interpretation records after source review.

Acceptance criteria:
- Records validate against the schema.
- Draft/source status is explicit.
- Composer does not introduce unsupported claims.

## Future Optional Layer

An AI narrative layer may be added later only as a formatter/storytelling layer. It must consume already calculated values and approved interpretation records, and it must not calculate or alter matrix values.
